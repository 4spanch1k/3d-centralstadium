# Центральный стадион, Алматы: 3D-выбор места

Веб-прототип: выберите трибуну, сектор и место на 3D-модели стадиона и посмотрите вид на поле с этого кресла. Модель и нумерация приблизительные; билет не выпускается, оплата не проводится.

## Быстрый старт

```bash
cd outputs/stadium-pilot
npm install
npm run dev      # http://127.0.0.1:5173 (или порт из вывода)
npm run build    # сборка в dist/
```

Ссылка на конкретное место: `#трибуна/сектор/ряд/место`, например `#east/30/3/3`.
Подробности реализации, оптимизации и источники ассетов: [outputs/stadium-pilot/README.md](outputs/stadium-pilot/README.md).

## Как устроен вид с места

1. **Живая сцена** (Three.js): чаша, 25 000 кресел через `InstancedMesh`, тени, на компьютерах затенение в контактах.
2. **Предрендеренные панорамы** (Blender Cycles) для 228 узлов по секторам: вид с места показывает ближайший узел своего сектора. Если панорамы нет, показывается живая сцена.

Пайплайн панорам: `window.__debug.exportScene()` (с `?debug=1`) → `work/blender/plan_nodes.py` → `work/blender/render_batch.py` → `work/blender/verify_panoramas.py`. Файлы панорам (`*.webp`, около 110 МБ) в git не попадают; их нужно пересчитать (около 3 часов) или раздать отдельно.

## Лицензии и источники
